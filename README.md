# ***Проект по созданию банковского приложения***

---

## Описание проекта
Приложение предназначено для обработки, маскировки и сортировки банковских данных. 
Безопасного отображения конфиденциальной информации (номеров карт и счетов) и удобной работы с данными о транзакциях.

## Структура приложения
Проект имеет простую и понятную структуру. Весь исходный код находится в папке src.

## Установка и использование
1. Склонируйте или скачайте репозиторий: [Мой репозиторий](https://github.com/AntonDav23/my_repository.git)
2. Импортируйте необходимые функции в свой скрипт:  
    - from src.generators import filter_by_currency, transaction_descriptions, card_number_generator
    - from src.masks import get_mask_card_number, get_mask_account
    - from src.widget import mask_account_card, get_date
    - from src.processing import filter_by_state, sort_by_date
    - from src.decorators import log
3. Запуск тестов (pytest)  
 - Запускает все тесты, написанные для проекта 
 - Генерация HTML-отчёта о покрытии
 - Создаёт интерактивный HTML-отчёт.Команда: `pytest --cov=src --cov-report=html`. Отчёт будет доступен в папке `htmlcov/index.html.`
4. Система логирования  
В проекте настроена система записи логов для отслеживания работы модулей.

Расположение: Папка logs/ в корне проекта.  
Перезапись: Логи перезаписываются при каждом запуске приложения.
Формат: `[Время]` - `[НазваниеМодуля]` - `[Уровень]` - `Сообщение`.  
Пример: `2024-06-05 12:00:00 - src.file_reader - INFO - Чтение CSV-файла: data/transactions.csv`  

## Документация
1. ** Модуль Decorators**  
Содержит декораторы для расширения функциональности.  
`@log(filename=None)`: Логирует выполнение функции (время, аргументы, результат или ошибку).
2. **Модуль Generators**  
содержит функции-генераторы для эффективной работы с данными.
- `filter_by_currency`: Фильтрует транзакции по валюте, возвращая итератор.  
- `transaction_descriptions`: Возвращает итератор с описаниями операций.  
- `card_number_generator`: Генерирует номера карт в заданном диапазоне.  
3. **Модуль masks**  
- `get_mask_card_number(card_number: str)`  
Маскирует номер банковской карты.  
**Вход**: "7000792289606361"  
**Выход**: "7000 79** **** 6361"
- `get_mask_account(account_number: str)`  
Маскирует номер банковского счета.  
**Вход**: "73654108430135874305"  
**Выход**: "Счет **4305"
4. **Модуль widget**
- `mask_account_card(input_str: str)`   
Универсальная функция. Обрабатывает строку и применяет нужную маску в зависимости от того, что найдено (карта или счет).
**Вход**: "Visa Platinum 7000792289606361"  
**Выход**: "Visa Platinum 7000 79** **** 6361"  
**Вход**: "Счет 73654108430135874305"  
**Выход**: "Счет **4305"  
- `get_date(date_string: str) -> str`  
Преобразует дату из формата ISO в формат ДД.ММ.ГГГГ.
**Вход**: "2024-03-11T02:26:18.671407"  
**Выход**: "11.03.2024"  
5. **Модуль processing**
- `filter_by_state(items: list, state_value: str = 'EXECUTED') -> list`  
Фильтрует список словарей по значению ключа state.
Аргумент state_value: По умолчанию 'EXECUTED'.
- `sort_by_date(items: list, reverse: bool = True) -> list`  
Сортирует список словарей по ключу date.  
Аргумент reverse: По умолчанию True (сортировка от новых к старым). Если передать False, сортировка будет по возрастанию.
- `get_transaction_amount_in_rub(transaction: dict) -> float | None`  
Принимает одну транзакцию (словарь) и возвращает сумму в рублях. Обрабатывает ошибки структуры данных.
6. **Модуль utils**
- `load_transactions_from_json(file_path: str) -> list`  
Загружает данные о транзакциях из JSON-файла. Возвращает пустой список, если файл не найден, пуст или содержит данные не в виде списка.  
7. **Модуль external_api**  
- `convert_to_rub(amount: float, from_currency: str) -> float`  
Конвертирует сумму из USD или EUR в рубли по текущему курсу через внешний API.  
Если валюта уже RUB, возвращает исходную сумму.  
В случае ошибки (нет интернета, неверный ключ) возвращает 0.0.
8. **Модуль file_reader**
Предназначен для загрузки финансовых операций из табличных файлов.  
- `read_csv_to_dicts(file_path: str) -> List[Dict]`: Считывает данные из CSV-файла и возвращает список словарей.  
- `read_excel_to_dicts(file_path: str) -> List[Dict]`: Считывает данные из Excel-файла (.xlsx) и возвращает список словарей.
